# YBI Foundation - Virtual Data Science with Python Trainee

## Week 1 Task: Data Acquisition, Cleaning, and Preprocessing

### 📌 Project Overview
This repository contains the complete implementation for **Week 1 Task** of the YBI Foundation Internship. The main objective of this task is to perform end-to-end data acquisition, exploratory data analysis (EDA), data cleaning, missing value handling, duplicate removal, and categorical feature encoding using Python.

---

### 📂 Repository Contents
* **`YBI_Data_Science_Week1.ipynb`**: Complete Google Colab / Python Notebook with code execution.
* **`dataset.csv`**: The raw dataset used for analysis and cleaning.
* **`Full_Code_Screenshot.png`**: High-resolution full-page scrolling screenshot of the executed notebook.

---

### 🛠️ Tech Stack & Libraries Used
* **Language:** Python
* **Environment:** Google Colab / Jupyter Notebook
* **Libraries:** 
  * `Pandas` (Data Manipulation & Cleaning)
  * `NumPy` (Numerical Operations)
  * `Scikit-Learn` (Label Encoding & Preprocessing)
  * `Matplotlib` & `Seaborn` (Data Exploration)

---

### ⚙️ Steps Performed
1. **Data Acquisition:** Loaded the dataset into Pandas DataFrame and performed structural inspection (`head()`, `info()`, `describe()`).
2. **Handling Missing Values:** Imputed numerical columns with median values and categorical columns with mode values.
3. **Data Cleaning:** Identified and removed duplicate records across the dataset.
4. **Categorical Encoding:** Converted categorical text columns into numerical integers using `LabelEncoder`.
5. **Output Verification:** Re-checked null values and verified dataset dimensions post-cleaning.
